# DayCalc Support

Use the [public issue tracker](../../issues) for reproducible bugs and feature
requests. GitHub issues are public, so remove personal event titles, locations,
attendee details, email addresses, diagnostics, and screenshots containing
sensitive information.

For questions that require sharing private material, contact
[erikmartens.developer@gmail.com](mailto:erikmartens.developer@gmail.com)
instead of opening an issue. Do not send passwords, Apple Account credentials,
calendar-account credentials, or device passcodes.

## Helpful Report Details

- DayCalc version and build, shown in the app's About screen;
- iOS version and device model;
- selected app language and appearance;
- Calendar and notification permission state, if relevant;
- minimal steps that reproduce the issue;
- expected and actual behavior.

DayCalc cannot provide emergency, medical, legal, or safety-critical calendar
or reminder guarantees. For urgent or safety-critical scheduling, use
appropriate dedicated services and independent verification.
