# Contributing

Thank you for helping improve DayCalc.

## Before Opening An Issue

1. Update DayCalc and iOS to the newest versions available to you.
2. Search the existing public issues for the same behavior or request.
3. Remove private calendar data, contact information, and other sensitive
   content from screenshots and descriptions.
4. Use the matching issue form and complete every required field.

Bug reports are most useful when they include the DayCalc version, iOS version,
device model, expected result, actual result, and minimal reproduction steps.
Feature requests should describe the user need before proposing a particular
implementation.

## Pull Requests

This repository does not contain the DayCalc application source. Changes to
generated legal documents must originate in the private app repository and be
published through its reviewed exporter workflow.

Please open an issue before preparing a pull request for public documentation.
Uncoordinated changes to generated legal files will not be accepted.

By submitting public issue or documentation content, you confirm that you have
the right to share it and allow it to remain available in this repository.
