# Security Policy

Do not disclose a suspected security or privacy vulnerability in a public
issue.

Send a concise report to
[erikmartens.developer@gmail.com](mailto:erikmartens.developer@gmail.com) with
the subject `DayCalc Security Report`. Include the affected app version,
reproduction steps, impact, and the minimum evidence needed to investigate.
Remove unrelated personal calendar data and never send passwords, credentials,
or device passcodes.

You will receive an acknowledgement when the report can be reviewed. Public
disclosure should wait until a fix or mitigation is available and coordinated.
